Language rule

  • Japanese is for the vibe. Page titles (おかえり。 授業を探す 管理), section headers (道順 評判 授業 口コミ 招待), the 一二三 numerals, the seal.
  • Days, dates and times are English on the website (Mon Wed · 8:00–9:25 AM, Checked Oct 2, 2026).
  • Plan day buttons stay 月火水木金土 — the selected day always reads "金曜日 · Friday".
  • Rating labels stay 評価 / 難易度 (no English beside them in the list).
  • Bottom menu: icons + English only — Guide · Search · Watches · Plan.

注意

Accessibility & hold

  • Kanji-only labels (評判, 口コミ, 待ち…) need an English accessible name: aria-label or visually-hidden text.
  • Wrap Japanese in lang="ja" so screen readers pronounce it.
  • Touch targets ≥ 44px, 2px ink focus ring, reduced-motion respected.
  • Saved / In Plan / Unlocked appear only after the server confirms.
  • Watches is on hold until the ed plan import lands; its boards show the intended direction only.

Build order suggestion: website screens (Guide · Search · Results · Report · Unlock · Owner) → Plan → Watches after ed plan import.
