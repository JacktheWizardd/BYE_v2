# BYE — AE86 landing prototype

Open `index.html` directly, or serve `frontEnd` with `python3 -m http.server 8765 --bind 127.0.0.1` and visit http://127.0.0.1:8765/landing-ae86/.

This is a buildless, local-only design prototype. All assets are local. The existing Spellbook handoff is unchanged.

Demo invite code: `WIZD-2026`. Invalid full codes count toward a three-attempt, 60-second UI lock. Empty/incomplete entries do not count. Reloading resets this demonstration; there is no production authentication or server enforcement. Success reveals a link to the AE86 app prototype.

The comparison uses illustrative names and scores, not live PCC or RMP data. The supplied AE86 image is included as a design reference; this prototype has not been published.

Fonts: Schibsted Grotesk and JetBrains Mono, with included OFL licenses.
