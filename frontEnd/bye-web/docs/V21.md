# v2.1 implementation and verification

Implemented October 31, 2026 using the corrected `frontEnd/mockups/HANDOFF-report-v2.1.md` and reference HTML. Work is local frontend code plus documentation; no API, database, authentication, or RMP cache changes.

Added pure BYE score calculation (50/50 rating/ease, ten pseudo-ratings), tied course leaders, reversible stable comparison sorts, diacritic-insensitive name-prefix search, compact zebra rows, source metadata, seat occupancy bars, one Sections refresh/status strip, and client-only ordering of downloaded reviews. Default score comparison resolves the full course's profile outcomes; search and schedule filters do not redefine the course leader. Unmatched/unknown values remain unscored. Initial course view remains neutral and report selection is explicit.

Retained five-minute freshness rather than the proposed ten minutes. No-data state is neutral. Failed saved-data reads do not claim PCC is unreachable. Outside the report the header identifies the last viewed course for the school/semester. Refresh all rereads saved counts and does not advance source timestamps. Source restrictions remain beside numeric availability; zero/inconsistent capacities do not produce misleading occupancy bars.
